Why I built Babble

I talk to my agents instead of typing

  • Speaking is more natural, and the agent gets more context
  • The Codex desktop app's dictation needed the whole app open, and it was heavy
  • Babble: light, instant, offline on Apple's Neural Engine
  • Built before Granola added dictation to its app
  • Today: meeting mode, on the same on-device pipeline

Simple and secure

Small on purpose

  • Reuses Babble's speech pipeline and decoder, no new models
  • Core Audio tap: audio permission only, no screen recording
  • Text only, files readable by my user only, nothing leaves the Mac
  • Cut: meeting detection, speaker ID, typed notes, saved audio
Where the AI failed, and the fix

Caught by me, by tests, by review

  • Agent: "assume headphones" → I asked for echo cancellation → voice-processed mic
  • First live test came back empty → Swift 6 crash on Core Audio's thread → fixed
  • Reviewers Fable 5.1 and Sol 6.1: a race that lost notes, AirPods silencing the mic → fixed
  • On-device model skipped titles → separate title request
Weakest part, what's next

The notes model is small

  • Weak: 8,192-token on-device model repeats topics and mishears names
  • Weak: speakers come from the audio source, not voices
  • Next: guided generation so the notes structure is enforced
  • Next: longer real calls, then tune the prompts
